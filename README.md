Entry for the [make.fun](https://make.fun) bounty
[The Dog Ate My Homework: Funniest Excuse](https://make.fun/c/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c).

`main.py` (pure Python stdlib, deterministic) writes a single line — under
200 characters — in which a dog explains why the homework got eaten, to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.

> The homework sat there all evening whispering 'bet you won't,' so I ate
> it. I have never backed down from a piece of paper in my life.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
